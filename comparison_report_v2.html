What this report covers

This report evaluates the current upgraded version of Mwalimu SNE AI against the November 17 baseline report. The classroom test runs the same benchmark protocol across all sixteen Grade 6 mathematics sub-strands under realistic rural classroom constraints: a 40-minute lesson, a class of 55 learners, the materials named in KICD notes, and a room with no power and no internet.

A passing lesson plan must name the topic correctly, use those materials, avoid a computer lab, mention the time allocations, include all four assessment levels (Exceeding, Meeting, Approaching, Below Expectations), and suit a large class with structured pod scaling.

SLM & Math Resolution (Eliminating the GSM8K Gap)

In the baseline report, Qwen 2.5 0.5B scored 38.51% on GSM8K, proving that using a small language model alone causes frequent arithmetic calculation mistakes.

How the current app solved this: The app employs a Neuro-Symbolic architecture. The built-in Procedural Math Synthesizer calculates all arithmetic, areas, fraction reciprocals, and exit ticket keys deterministically in native code (100% mathematical precision). The Qwen 2.5 0.5B SLM is guided by structured RAG prompts to write the adaptive classroom actions around these verified numbers, completely eliminating math hallucinations.

Specialized SNE Accommodations Matrix

Every sub-strand is now accompanied by specialized pedagogical accommodations for 6 SNE categories: Hearing Impairment (KSL glosses, 3-color desk cards, horseshoe seating), Visual Impairment (5 cm knotted ropes, audio guides), Dyslexia (visual storyboards, reading cutout windows, zero spelling penalty), Dyscalculia (CPA Ten-Frames, double-sided counters, formula flip cards), ADHD (3-min micro-sprints, visual timers, active squad roles), and Motor Challenges (20° slant boards, adapted grips, Pilot & Scribe protocol).
